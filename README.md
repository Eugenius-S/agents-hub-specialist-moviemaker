# The Video Editor specialist for agents-hub

A permanent hub agent: edits ad and product videos in After Effects, and without AE does it on its own (ffmpeg, HTML recording). Remembers the wins and failures of past edits.

- Starts only on a task from the owner or another session.
- One format first, until approved; "edited" comes before rendering.
- A clear AE project structure, the two latest versions.
- Hands texts, prompts and illustration animation to specialists; credits only with the owner's "yes".

It is installed from the hub's specialist catalog. The tools from `hub-plugin.json` → `agent.tools.optional` are granted by the hub if its catalog has them. The `editing-principles` skill is a set of editing principles with numbers and sources. Check after installing: the cases in `evals/cases.md`.
